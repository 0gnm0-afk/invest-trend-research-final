# 이동평균선 연구의 최종 결과

연구는 종료했다. 최종 결과와 목적·시행착오·규약·핵심 계산 코드를 보존한 공개 기록이다.

| 질문 | 최종 보고서 | 확인한 결과 |
|---|---|---|
| MA 신호로 나누어 팔면 하락 방어와 상승 보유를 함께 개선하는가? | [4분할 매도](docs/research/ma-exit4-research-2026-10-16.md) | 낙폭 완화는 관측했지만 보유 대비 수익 우위는 입증하지 못했다. |
| 큰 하락을 초기에 경고할 수 있는가? | [15% 초기 경고](docs/research/ma-warning15-research-2026-10-16.md) | 동결한44조건의 보류 종목 검증에서 충분한 추가 예측력 통과0. |
| 신호가 발생할 때 이미 얼마나 하락했는가? | [신호 시점 낙폭 기술통계](docs/research/ma-dd-descriptive-2026-10-17.md) | 신호가 늦어질수록 이미 내린 폭이 커지는 경향과 정의/표본 민감도를 구분했다. 미래 하락 확률이 아니다. |
| 역배열에서 절반을 팔고 반등에 되사면 나아지는가? | [6개 재진입 규칙](docs/research/ma-reentry-research-2026-10-17.md) | 비용 후 주식수·연결자산에서 보유를 개선할 유의한 우위를 발견하지 못했다. |
| 전체 시간축을9조합의 보유/회피 구간으로 나누면 나아지는가? | [9조합 최종 타이밍](docs/research/ma-timing-segments-2026-10-18.md) | 전량/절반 회피 모두 고정 표본에서 보유 하회, 보정 검증 우위0. |

[연구 목적과 시행착오](HISTORY.md) · [하락률 문헌 검토](docs/research/ma-warning-thresholds-2026-10-16.md) · [제외 자료·재현 한계](OMITTED_DATA.md).

표와 그림의 근거 집계는 `runtime`의 연구별 하위 폴더에, 계산 소스/규약은 `scripts/research`에 있다. 공개 소스는 과거 환경의 스냅샷이며 즉시 실행 가능한 독립 패키지로 새로 구현한 것은 아니다. 연구 수치의 의미와 한계는 각 본편을 따른다. 운영 매매·계좌·알림에는 적용하지 않았다.
