# 공개에서 제외한 자료와 복원 범위

원시 OHLCV/거래량/시총·공급자 원응답·취득 다운로드·설치 패키지·대형NPZ·상세 사건/체결/경로 원장·초안은 이 공개 묶음에 넣지 않았다. 개인의 실제 거래·계좌·일지·인증/운영DB 감사 값과 개인 경로/비공개 링크도 제외했다. 개인 기록을 검사하는 함수와 그에 의존한 검사/보고서 생성 소스는 공개판에서 비활성화하거나 제외했다.

이 페이지로 연결되는 원래 상세 원장 링크는 최종 집계표와 같은 파일이 아니다. 해당 상세 파일은 공개 보관 범위에서 제외했다는 표시이며 다운로드를 제공하는 척하지 않는다. 원래 결과표·최종 집계·PNG·연구 규약과 계산 소스의 복원은 가능하지만, 폐기한 중간 계산 상태는 원본 입력과 당시 환경을 연결해 재계산해야 한다.

실제 매매 성과와 혼동하지 않도록 본편의 개인 감사 문단은 일반적인 연구 평가 범위로 치환했다. 원본과 공개 편집본은 `provenance/source-map.json`의 별도SHA-256으로 구분한다. 과거 원본 검증 영수증은 당시 파일의 기록이며 공개판의 현재 해시는 `MANIFEST.json`을 따른다.

핵심 코드 스냅샷은 기존 workbench_paths/atomic_io와 당시 데이터·Python 라이브러리를 참조한다. 수집기와 운영 계좌 기능을 공개 실행 패키지로 묶지 않았다. 연구 결과를 수익성 보장이나 새 자동매매 규칙으로 해석하지 않는다.
