# 하락 장기 연구의 자료 범위와 평가 가능 기간

미국·한국의 **전체 저장 종목 7,483개를 모두 점검**했다. 주 비교 기간은 2010-10-01~2025-09-30의 180개월이며, 종목별 가장 이른 저장 이력부터의 결과도 별도로 계산한다. 이력이 15년 미만이라는 이유로 종목을 탈락시키지 않는다. 다만 과거 준비 기간·미래 평가 기간·완료된 추세를 확인할 수 없는 날짜는 분모에서 제외한다.

| 항목 | 한국 | 미국 |
|---|---:|---:|
| 점검한 전체 저장 종목 | 2,637 | 4,846 |
| 사용 가능한 가격·L1 캐시 | 2,610 | 4,683 |
| 원자료 처음~끝 간격이 15년 이상 | 1,380 | 1,957 |
| 15년 이상 이어지는 유효 가격 구간이 하나 이상 | 272 | 1,572 |
| 전체 이력에서 평가 가능한 종목 | 2,564 | 4,537 |
| 주 15년 창에서 평가 가능한 종목 | 2,513 | 4,385 |
| 주 15년 창의 유효 가격 봉 | 6,668,482 | 10,588,622 |
| 주 15년 창의 공통 평가 가능 종목·거래일 | 5,915,843 | 9,802,408 |
| 과거 65봉 부족으로 제외 | 338,301 | 637,283 |
| 미래 126봉·L1 자료 부족으로 제외 | 401,106 | 140,737 |
| 나머지 중 미완료 하락으로 제외 | 13,232 | 8,194 |
| 전체 이력의 공통 평가 가능 종목·거래일 | 8,797,580 | 15,069,996 |

공통 평가 가능 여부는 신호별 준비 기간을 적용하기 전이다. 따라서 최종 신호별 종목 수와 거래일 수는 더 작을 수 있다. 사용 가능한 캐시 7,293개가 모두 모든 지표의 성과 분모에 들어간다는 뜻은 아니다. 가격 캐시를 만들 수 없는 190개는 너무 짧은 자료 161개, 80봉 이상 연속 구간 부재 27개, 빈 자료 2개다.

원자료 범위는 한국 1975-01-04~2026-09-30, 미국 1990-01-02~2026-09-30이다. 공통 평가 가능 범위는 한국 1975-03-25~2026-03-26, 미국 1990-04-04~2026-03-31이다. 이는 각 시장의 가장 바깥 날짜이며 모든 종목이 그 전체 기간을 덮는다는 뜻은 아니다. `coverage-stocks.csv`에서 종목별 실제 날짜와 구간을 확인할 수 있다. `coverage-years.csv`는 주 15년 창에 잘라 넣은 성능표가 아니라 전체 저장 이력의 연도별 자료량이다.

저장된 활성 원본 종목은 KOSPI/KOSDAQ 2,604개와 NASDAQ/NYSE 4,843개다. 당시 수집 범위는 `ACTIVE STOCK commonShare=true`였으며, 여기에 한국 과거 보조 이력 33개와 미국 차트 보조 ADR 3개(BP, NVO, TSM)가 더해진다. 모든 활성 원본 종목이 inventory에서 대조됐고 누락 종목은 없었다. 운영 제외였던 57개도 이번 연구용으로 재시도했으며, 56개는 캐시가 생겼고 NUTR은 유효 38봉으로 너무 짧았다. 운영 제외 정책은 바뀌지 않았다.

활성 원본 수집 기록의 시작 정책은 `provider_earliest_available`이며, 한국 2,604개·미국 4,843개 모두 `provider_end_reached=true`다. 따라서 해당 저장 원본에서는 공급자가 반환하는 최초 이력까지 수집했다는 근거가 있다. **보조 ADR 3개에는 이 근거를 적용할 수 없다.** 이들 원본 차트 캐시는 모두 2016-01-04부터이며, 관련 저장 coverage/catalog와 차트 DB를 다시 확인했지만 2016년 이전 이력은 찾지 못했다. 실제 상장일이나 공급자의 최장 이력이 2016년이라는 뜻은 아니다. 이 3개는 저장된 최초부터 포함하되 15년 미확보로 명시한다.

‘전체’는 **이번에 보유한 전체 저장 종목**이라는 뜻이다. 각 과거 시점에 상장돼 있던 모든 종목·상장폐지 종목·모든 ADR을 확보한 생존편향 없는 자료는 아니다. 한국 과거 보조 이력 33개가 이 한계를 해소하지도 않는다.

기존 가격 처리와 L1 정의를 유지하므로 무효/거래량0 봉 제거, 확인된 거래일 누락, 10일 초과 달력 공백에서 구간을 끊는다. 마지막 조건은 정상적인 긴 연휴도 끊을 수 있다(예: 삼성전자 2017-09-29~2017-10-10). 따라서 구간 단절을 모두 공급자 오류라고 해석해서는 안 된다. 과거 한국 거래 달력의 불일치 경고와 중단도 기존 처리 그대로다. 처음~끝의 15년 간격, 연속 가격 15년, 평가 가능한 연속 15년은 서로 다르다.

이번 표는 방향 중립인 기존 가격·L1 배열을 재사용하고 **하락 경계로 다시 계산**했다. 상승 연구의 평가 가능일이나 미완료 상승 수치를 옮기지 않았다. 독립 단순 반복문으로 100,000개 합성 날짜의 하락 경계와 시작점 미완료·구간 공백 예제 2개를 확인했다. 두 시장·세 기간에서 `가격 봉 = 평가 가능 + 과거 부족 + 미래 부족 + 미완료 하락`이 모두 일치했다. 상승 연구와 같은 가격 범위·구간 등 74,830개 항목도 일치했다. 검증 기록은 `coverage-validation.json`이다.

추가 가격 수집·계좌 조회·운영 자료 수정은 수행하지 않았다. 재현 코드는 `scripts/research/downtrend_longhistory/coverage_audit.py`, 입력 inventory는 `runtime/downtrend-longhistory-20261029/inventory.json`이다.
